# 🔗 Useful Links, Tools & Community Resources

Curated references for **Linux gaming**, **Wayland compositors**, and **low-latency dual-PC game streaming**.

---

## 🎮 Linux Gaming & Launch References

* **[Linux Gamer Life (`linuxgamerlife.net`)](https://linuxgamerlife.net)**
  * Terminal-styled Linux gaming hub documenting Windows-to-Linux migrations, distro comparisons (including CachyOS), Steam launch commands, and open-source desktop toolkits.

---

## 📡 Low-Latency Game Streaming & Virtual Displays

* **[Nonary/Vibepollo (`://github.com`)](https://://github.com)**
  * Enhanced fork of Apollo/Sunshine with automated virtual displays, native client resolution/refresh matching, **PyroWave** low-latency GPU wavelet streaming, and **Remote Monitor** support.
  * *Notes:* Runs as a Windows service with full WGC virtual display automation, and includes an Arch/CachyOS Linux beta (tested primarily on Plasma 6 Wayland).

* **[Nonary/moonlight-qt (`://github.com`)](https://://github.com)**
  * Custom Moonlight desktop client fork built to pair with Vibepollo, unlocking **VRR frame pacing**, the **PyroWave** codec, and **Remote Monitor** mode over wired LAN.

---

## 🪐 Compositor & Shell Upstream Repositories

* **[Umbriel Compositor (`://github.com`)](https://://github.com)** — Wayland scrolling compositor with per-workspace layouts, native scratchpads, and GLSL border/animation shaders.
* **[Noctalia Shell (`://github.com`)](https://://github.com)** — Modular shell, panels, and IPC suite integrated with Umbriel.
